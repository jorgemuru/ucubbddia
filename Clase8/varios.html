Preparar la Base de Datos MySQL

Creamos la tabla con las preferencias

Primero, necesitamos crear la tabla en tu base de datos MySQL local con los datos de las personas y sus temperaturas preferidas:

-- Crear la tabla grupo
CREATE TABLE grupo (
    id INT PRIMARY KEY AUTO_INCREMENT,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(100),
    temp_preferida DECIMAL(4,2) COMMENT 'Temperatura preferida en °C',
    country VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Insertar datos de ejemplo

Conectar a MySQL Local

Importamos la tabla grupo

Requisito: Instalar MySQL Connector/ODBC o MySQL .NET Driver
Configuración de conexión:
Servidor: localhost
Puerto: 3306
Base de datos: [tu_base_de_datos]
Usuario: root
Contraseña: [tu_contraseña]
  1. Obtener datos → Base de datos → MySQL
  2. Ingresar servidor y base de datos
  3. Modo: Importar (recomendado)
  4. Ingresar credenciales
  5. Seleccionar tabla grupo
  6. Click en "Cargar"
Consejo:

Si usas "Importar", los datos se cargan en memoria de Power BI. Si usas "DirectQuery", Power BI consulta MySQL en tiempo real cada vez que interactúas con el reporte.

5

Crear Visualización y Análisis

Comparamos temperaturas y creamos el reporte

Visualizaciones recomendadas:
Tabla de Personas
  • Nombre completo
  • Temperatura preferida
  • Temperatura actual (de la API)
  • Diferencia
  • Estado: ✅ Cómodo / ❌ Incómodo
Gráficos
  • Tarjeta: Temperatura actual grande
  • Gráfico de barras: Preferencias vs Real
  • Gráfico circular: % Cómodos vs Incómodos
  • Mapa: Ubicación de personas
Cálculo de confort (sin DAX - usando Power Query):
-- En Power Query, agregar columna personalizada:
= if Number.Abs([temp_actual] - [temp_preferida]) <= 2 
  then "✅ Cómodo" 
  else if [temp_actual] > [temp_preferida] 
       then "❌ Calor" 
       else "❌ Frío"
Resultado: Una tabla que muestra si cada persona está cómoda con la temperatura actual de Montevideo según sus preferencias personales.
6

Publicar y Configurar Actualización

Automatizar la actualización de datos

Publicar en Power BI Service:
  1. Click en "Publicar"
  2. Seleccionar área de trabajo
  3. Esperar a que se suba el archivo
Configurar Gateway:
Para MySQL local, necesitas instalar On-Premises Data Gateway
  1. Descargar Gateway desde powerbi.com
  2. Instalar en la misma PC que tiene MySQL
  3. Configurar credenciales de MySQL
  4. Programar actualización (ej: cada 1 hora)
Frecuencia de actualización:
  • API Web: Cada hora (clima cambia)
  • MySQL: Según necesites (diario, semanal)
Acceso móvil:

Power BI tiene app para iOS y Android. Puedes ver el reporte desde tu celular con el clima actualizado.
