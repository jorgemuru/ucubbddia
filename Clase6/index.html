El recorrido de la clase

El objetivo es que cada uno pueda, en su propia PC, cargar un dataset desde MySQL hacia Power BI y armar una primera visualización. La ruta:

  • Requisitos previos — qué tiene que estar instalado antes de empezar.
  • Preparar la base — importar el dataset de práctica techventas.
  • Conectar — usar el conector nativo "Base de datos MySQL" de Power BI.
  • Elegir datos — seleccionar una tabla o una vista SQL y cargarla.
  • Visualizar — crear el primer gráfico y refrescar datos.
Intercalados hay quizzes de repaso y ejercicios prácticos para hacer en tu máquina mientras avanzamos.
1 Requisitos previos

¿Qué necesito instalado?

La integración con MySQL no funciona sola: Power BI necesita un componente intermedio para "hablar" con MySQL. Esto es lo que tiene que estar listo:

Power BI Desktop

Gratis desde Microsoft Store o el sitio de Power BI. Es donde armamos los reportes.

MySQL Server local

El servidor corriendo en tu PC (MySQL Community Server) y DBeaver como cliente para administrarlo. Anotá usuario, contraseña y puerto (por defecto 3306).

El paso que más se olvida: Power BI requiere el conector MySQL Connector/NET instalado en Windows. Sin él, al elegir MySQL te pedirá instalarlo. Descargalo de la web oficial de MySQL (dev.mysql.com → Connector/NET) e instalá antes de abrir Power BI.
2 Preparar la base de datos

Importamos techventas

Usá el script techventas.sql (te lo paso al final). Crea una base con una tabla ventas (68 registros de una tienda de tecnología) y una vista vw_resumen_ventas.

  • Abrí DBeaver y creá/abrí tu conexión a MySQL local (Database → New Connection → MySQL).
  • Con la conexión seleccionada: SQL Editor → Open SQL script y elegí techventas.sql.
  • Ejecutá todo el script con Execute SQL Script (Alt+X), no "Execute statement", para que corra todas las sentencias.
  • Refrescá el árbol de la izquierda (F5) y verificá con SELECT * FROM ventas; que aparezcan los datos.
verificación.sql
USE techventas;
SELECT categoria, SUM(precio_unitario * cantidad) AS total
FROM ventas
GROUP BY categoria
ORDER BY total DESC;  -- ¿qué categoría vende más?

3 Conectar Power BI a MySQL

"Obtener datos" → Base de datos MySQL

  • En Power BI Desktop: Inicio → Obtener datos → Más…
  • Buscá "MySQL" y elegí Base de datos MySQL.
  • En Servidor escribí localhost (o localhost:3306).
  • En Base de datos escribí techventas.
  • Credenciales → pestaña Base de datos → tu usuario y contraseña de MySQL.

◉ Importar   ○ DirectQuery
Importar vs. DirectQuery: para la clase usamos Importar (trae los datos a Power BI, más rápido para visualizar). DirectQuery consulta MySQL en vivo en cada interacción — útil con datos enormes o que cambian a cada segundo.
4 Elegir tabla o vista

El Navegador: tabla o vista SQL

Power BI abre el Navegador con todos los objetos de techventas. Acá aparecen tanto las tablas como las vistas — y para Power BI son casi lo mismo: una fuente de filas y columnas.

Tabla ventas

Los datos crudos: precio, cantidad y descuento por separado. Vos calculás el total después en Power BI.

Vista vw_resumen_ventas

Ya trae el total_neto calculado en SQL. Power BI recibe el dato listo para graficar.

  • Tildá el objeto que quieras (probá la vista vw_resumen_ventas).
  • Vista previa a la derecha para confirmar que son los datos correctos.
  • Cargar para traerlos, o Transformar datos para limpiarlos primero en Power Query.

5 Crear la primera visualización

Del dato al gráfico

Con los datos cargados, en la vista Informe aparece el panel de Campos a la derecha con tus columnas. Armemos un gráfico de barras de ventas por categoría:

  • En Visualizaciones elegí el ícono de gráfico de columnas/barras.
  • Arrastrá categoria al área Eje X.
  • Arrastrá total_neto al área Eje Y (Power BI lo suma automáticamente).
  • ¡Listo! Ya tenés ventas totales por categoría. Agregá vendedor como Leyenda para desglosar.
Refrescar datos: si cambiás algo en MySQL, en Power BI usá Inicio → Actualizar para volver a traer los datos (recordá que en modo Importar trabajás sobre una copia).

Cuatro preguntas que recorren toda la clase.

Cuando algo no anda

Problemas frecuentes

"Falta el conector / no aparece MySQL"

Instalá MySQL Connector/NET desde dev.mysql.com y reiniciá Power BI.

"Access denied" al conectar

Usuario o contraseña mal. Verificá probando la conexión en DBeaver y, en Power BI, usá la pestaña Base de datos (no Windows).

"No se puede conectar al servidor"

El servicio MySQL no está corriendo, o el puerto no es 3306. Revisá Servicios de Windows, o probá la conexión desde DBeaver (botón Test Connection).

"Las fechas salen como texto"

En Power Query, seleccioná la columna y cambiá el tipo de dato a Fecha antes de Cerrar y aplicar.
