Structured Query Language
Concepto

SQL: pedir el resultado, no programar el camino

Lenguaje declarativo

SQL permite definir qué información se desea recuperar o modificar, dejando al DBMS la responsabilidad de decidir cómo ejecutarlo.

Estándar transversal

Se usa en PostgreSQL, Oracle, MySQL, SQL Server y otros motores. Para un analista, SQL es una habilidad portable.

Componentes SQL
Sub lenguajes

DDL, DML y DCL: tres miradas sobre la base

DDL

Define objetos: tablas, vistas, restricciones, índices, esquemas.

DML

Manipula datos: INSERT, UPDATE, DELETE y SELECT.

DCL

Controla permisos y acceso. Complemento esencial para datos sensibles.

En IA, estas capas ayudan a definir, proteger, consultar y transformar los datos antes del entrenamiento.

Views
Vistas

Vistas: consultas guardadas como tablas virtuales

¿Para qué sirven?

Permiten encapsular consultas, simplificar reportes y exponer solo las columnas necesarias.

Son muy útiles para publicar datasets analíticos sin repetir la misma consulta compleja.

CREATE VIEW vw_estudiantes_analisis AS
SELECT id_estudiante, edad, departamento, fecha_registro
FROM Estudiante
WHERE edad IS NOT NULL;

Buenas prácticas
Atención con DELETE y DROP

Una consulta sin WHERE puede borrar demasiado

Riesgo

DELETE FROM Estudiante;
DROP DATABASE instituto;

La primera elimina todas las filas. La segunda elimina la base si el DBMS y los permisos lo permiten.

Recomendaciones

  • Usar siempre WHERE en DELETE y UPDATE.
  • Ejecutar antes un SELECT con la misma condición.
  • Trabajar con transacciones cuando sea posible.
  • Restringir permisos de DROP en producción.
Consulta base
SELECT

SELECT: la herramienta principal del analista

SELECT [DISTINCT] columnas
FROM tablas
WHERE condición
GROUP BY columnas
HAVING condición_de_grupo
ORDER BY criterio;

Orden lógico

  1. FROM
  2. WHERE
  3. GROUP BY
  4. HAVING
  5. SELECT
  6. ORDER BY

Este orden ayuda a razonar errores y resultados inesperados.

Legibilidad
Ambigüedad y alias

Nombrar bien evita errores y mejora lectura

-- Ambiguo
SELECT nombre
FROM Estudiante, Curso
WHERE Estudiante.id_curso = Curso.id;
-- Calificado y legible
SELECT E.nombre AS NombreEst,
       C.nombre AS NombreCur
FROM Estudiante AS E, Curso AS C
WHERE E.id_curso = C.id;

GROUP BY
Agregaciones

De filas individuales a indicadores

SELECT departamento,
       COUNT(*) AS cantidad,
       AVG(edad) AS promedio_edad,
       MIN(edad) AS edad_min,
       MAX(edad) AS edad_max
FROM Estudiante
GROUP BY departamento
HAVING COUNT(*) BETWEEN 1 AND 5;

Uso analítico

COUNT, AVG, MIN, MAX y SUM transforman registros en métricas. Son la base para dashboards, indicadores y variables de modelos.

Algunos motores aceptan alias; otros no. Para portabilidad, repetir la función.

SELECT
  c.id_cliente,
  COUNT(v.id_venta) AS compras,
  SUM(v.importe) AS gasto_total,
  AVG(v.importe) AS ticket_promedio
FROM Cliente c
JOIN Venta v ON c.id_cliente = v.id_cliente
WHERE v.fecha >= '2026-01-01'
GROUP BY c.id_cliente;
